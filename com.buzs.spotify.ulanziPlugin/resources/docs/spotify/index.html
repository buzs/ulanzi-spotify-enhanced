Local setup guide

Connect Spotify Enhanced

Create your own Spotify Developer app and connect it to the Ulanzi D200 plugin.

Spotify Premium is required. Spotify Web API playback control only works with Premium accounts.

Redirect URI

Add this URI to your Spotify Developer app:

http://127.0.0.1:30901/oauth2callback

If the Ulanzi settings panel shows a different URI, use the exact URI shown there instead.
